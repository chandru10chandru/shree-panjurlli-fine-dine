## 🏛️ About Shree Panjurlli Fine Dine

Located in the bustling culinary hub of **Tilakwadi, Belagavi** (beside D-Mart at Kuber Plaza), **Shree Panjurlli Fine Dine** (SPG — Shree Panjurlli Group) brings together the deep coastal roots of Karnataka with regal hospitality. 

Known across Belagavi for authentic **Mangalorean coastal seafood**, traditional **Kundapura Ghee Roasts**, aromatic **Savaji Mutton Curries**, slow-dum **Basmati Biryanis**, and refreshing **Signature Gadbad Sundaes**, our sanctuary is designed for family dinners, banquets, and celebrations.

---

## ✨ Features

- **🏛️ Immersive Visual Gallery & Lightbox**: High-resolution gallery capturing our stone-carved temple reception, teak jaali medallions, hanging honeycomb garden canopy, and private family booths.
- **📜 Interactive Categorized Menu**: Fast, filterable food menu featuring Starters, Coastal Seafood, Savaji Delicacies, Biryanis, Vegetarian Specialties, Tandoor & Breads, and Desserts with dietary indicators and spice scales.
- **📋 High-Resolution Physical Menu Viewer**: Dual-tab modal allowing guests to view our official physical Dine-In Menu cards (Veg & Non-Veg).
- **📅 Table Reservation with WhatsApp Sync**: Interactive table booking form collecting dining preferences, party size, and date/time slots with automated WhatsApp confirmation messages.
- **🛵 Quick Online Delivery Deep Links**: Modal connecting directly to official listings on **Swiggy** and **Zomato**.
- **📍 Visit & Landmark Location**: Embedded interactive Google Map with driving directions, operating hours, and landmark cues (Beside D-Mart, Tilakwadi).
- **📱 Sticky Mobile Action Bar**: Bottom quick-action bar for mobile guests to call reception, locate on map, or reserve a table instantly.
- **🔍 Local SEO & Schema.org**: Rich Restaurant JSON-LD structured data and Open Graph meta tags optimized for Belagavi local food searches.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/chandru10chandru/shree-panjurlli-fine-dine.git
   cd shree-panjurlli-fine-dine
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173`.

### Production Build

To generate the optimized production bundle in `/dist`:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
